Install with M-Flasher

Use this alternative when browser OTA is unsupported or you need recovery. Once the unit is in USB download mode, this workflow works independently of the running firmware. AQUORA, SLOOP, Felucca, factory firmware and SLAP-5 can all use this route.

Download SLAP-5 v0.1.46 experimental Get the latest M-Flasher
  1. Open the official M-Flasher release and select the download for Windows, macOS or Linux. If you already have M-Flasher, compare your version with the release heading. If you can’t find your version, get a fresh copy from the release page and open it yourself.
  2. Connect the FM-1 directly with a USB data cable. Close browser MIDI tools and other music apps. Open M-Flasher and choose Download Mode if offered. With m-bootloader, hold REC at power-on. For other configurations, follow the M-Flasher download-mode guide. Cancel any disk-format prompt.
  3. Once M-Flasher reads the device, inspect Device info. This build targets the M-VAVE FM-1 with a 1 MiB 0x856014 flash chip, chip key 0x980F and a compatible V15-style application layout. The 0xB36014 flash revision and unverified bootloader layouts are outside this build’s support. If any value or layout is unclear, stop at the read-only screen.
  4. Choose Install firmware (.fwsc) and open SLAP-5-0.1.46.fwsc. Review the flash map before confirming. The write plan must stay in 0x4000–0x92FFF and preserve the boot area and user-data regions. Decline any separate bootloader installation offer. Stop if the plan or M-Flasher reports a compatibility warning you can’t resolve.
  5. Let M-Flasher save its automatic backup, complete the write and verify it. Keep the cable connected during the operation. After verification, restart and confirm SLAP-5 boots. Use browser detection below to check for FM-1_75000146.
